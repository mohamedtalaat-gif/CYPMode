# Icon of the pages

The three files here (`favicon-32.png`, `favicon.ico`, `apple-touch-icon.png`) are the icons of the site [mohamedtalaat-gif.github.io](https://mohamedtalaat-gif.github.io), copied from its `public` folder, so that a tab of the notebook, the explorer, the map, the card, or the film shows the same icon as the site that frames them. The Pages workflow (`.github/workflows/pages.yml`) puts them on every page that it publishes and at the root of the published site, and `cypmode/audit/project_map.py` puts the 32-pixel file inside the page of the map.
