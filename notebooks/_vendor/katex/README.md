# KaTeX (vendored)

KaTeX 0.16 (`katex.min.js`, `contrib/auto-render.min.js` as `auto-render.min.js`, `katex.min.css`) and its fonts, MIT licensed (see `LICENSE`). They typeset the equations of the
HTML and PDF exports of the notebook without a network connection. The exporter (`notebooks/build_exports.py`) inlines the scripts, the stylesheet and the fonts into the HTML file.
Upstream: https://katex.org
